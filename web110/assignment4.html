Through the first activity mentioned, I learned both the history of these attacks and how best to guard against them. I use Email and Outlook often, so knowing how to minimize the time needed for each task is a useful skill to have. Quality is maintained, yet work can be done much faster. Properly conveying information while being respectful is a skill needed in workplaces and, therefore, an integral activity to learn from.
