  • SELECT CustomerID, CustomerName
    FROM Customers;
  • SELECT CustomerName, Address, City, PostalCode
    FROM Customers
    WHERE Country = "UK";
  • SELECT ContactName, CustomerName
    FROM Customers
    ORDER BY ContactName;
  • SELECT COUNT(*)
    FROM Customers;
  • SELECT Country, COUNT(*) AS Customers
    FROM Customers
    GROUP BY Country;
  • SELECT Country, COUNT(*) AS Customers
    FROM Customers
    GROUP BY Country
    ORDER BY COUNT(*) DESC, Country ASC;
  • SELECT Country, COUNT(*) AS Customers
    FROM Customers
    GROUP BY Country
    HAVING (COUNT(*)) > 5
    ORDER BY COUNT(*) DESC, Country ASC;

Summary Paragraph

  Databases are vital parts of today’s technological world. Because of this, it is very important to know how to utilize SQL -- the standard language for databases -- in order to view, manipulate, and integrate data. In order to record information in the tables, one must understand how to use commands such as INSERT, DELETE, UPDATE, etc. Similarly, to organize the entries and which ones are outputted, one needs to be familiar with commands such as SELECT, ORDER BY, WHERE, etc. These activities allow for practice with these aforementioned tools.
