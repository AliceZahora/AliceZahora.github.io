What is CSS?

CSS, or Cascading Style Sheets, is what is used to define the styling of a page. With this language, webpages can be transformed into organized, aesthetic, and clearly navigable sites through the manipulation of layout, design, etc.

Implementation

  CSS can be either inline, internal, or external. For the first, simply place your CSS inside your html element tag. For example: 

                            •  <p style='background-color: red'>
  Internal integration requires opening and closing "style" tags in the "head" section of your html. For example: 
                            •  <head>
                                    <style>
                                        p {
                                            background-color: red;
                                        }
                                    </style>
                            </head>
  External integration requires a seperate file for your CSS and a link to that sheet within your "head" tag. For example: 
                            •  <head>
                                    <link rel="stylesheet" type="text/css" href="style.css">
                                </head>

Important Terms

  • Selectors: Define which elements should be affected
  • Declarations: Placed between curly braces after selector, sets of property-value pairs separated by a semi-colon
  • Properties: Attribute categories to be applied to selected elements
  • Values: What the properties should be set equal to
  • Combinators: Used with Selectors to make selection more specific, defines relationships between elements
  • Pseudo Classes: Used with Selectors to make selection more specific, defines state of element
